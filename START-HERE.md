## If GitHub is new to you

A few names make more sense once someone explains them:

- A **repository** is a project's files, together with the history of their changes.
- A **README** is the introduction you're usually shown first.
- A **commit** records a set of changes.
- An **issue** gives a specific problem or improvement a place to be tracked.
- A **pull request** lets someone propose changes for review.
- A **Discussion** is a place to talk things through.

You can help by saying, "I don't understand this part." That's enough to tell me where an explanation needs more work.

Bookmark the [journal](journal/README.md) if you want to come back. GitHub's Watch menu lets you choose repository notifications.
